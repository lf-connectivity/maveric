# Agentic Mobility Visualization

Enhanced visualization tools for analyzing UE mobility tracks generated by the Agentic Mobility system.

## Quick Start

```python
from radp.digital_twin.agentic_mobility.visualization import (
    plot_ue_tracks,
    plot_ue_tracks_comparison,
    plot_ue_subset,
)

# Load your data
import pandas as pd
df = pd.read_csv("generated_ues/agentic_mobility_75UE_50ticks.csv")

# Plot all UEs without legend (recommended for many UEs)
plot_ue_tracks(df, legend=False)

# Plot specific UEs with legend
plot_ue_tracks(df, legend=True, ue_ids=[0, 1, 2, 3, 4])

# Quick subset plotting
plot_ue_subset(df, ue_ids=[0, 5, 10])
```

## New Enhanced Functions

### `plot_ue_tracks()`

Main plotting function with full control over visualization.

**Key Features:**
- **Legend control**: `legend=True/False` to show/hide legend
- **UE filtering**: `ue_ids=[...]` to plot specific UEs
- **Customization**: Control figure size, titles, markers, arrow width
- **Smart legend**: Auto-truncates when too many UEs
- **Optimized**: Fast performance even with large datasets

**Parameters:**
```python
plot_ue_tracks(
    df,                          # DataFrame with ['mock_ue_id', 'tick', 'lat', 'lon']
    legend=False,                # Show/hide legend
    ue_ids=None,                 # List of UE IDs to plot, or None for all
    figsize=(12, 8),             # Figure size
    title=None,                  # Custom title
    show_start_points=True,      # Mark starting points
    show_end_points=False,       # Mark ending points
    arrow_width=0.002,           # Arrow width
    max_legend_items=20,         # Max legend items before truncation
)
```

**Examples:**

```python
# Example 1: All UEs, no legend (best for 20+ UEs)
plot_ue_tracks(df, legend=False)

# Example 2: First 5 UEs with legend and end markers
plot_ue_tracks(
    df,
    legend=True,
    ue_ids=[0, 1, 2, 3, 4],
    show_end_points=True,
    title="First 5 UEs - Detailed View"
)

# Example 3: Single UE with large figure
plot_ue_tracks(
    df,
    legend=True,
    ue_ids=[7],
    figsize=(14, 10),
    show_end_points=True
)

# Example 4: Custom styling
plot_ue_tracks(
    df,
    legend=True,
    ue_ids=[0, 5, 10, 15],
    arrow_width=0.004,  # Thicker arrows
    title="Selected UEs with Enhanced Arrows"
)
```

### `plot_ue_subset()`

Convenience function for quickly plotting a subset of UEs with sensible defaults.

**Parameters:**
```python
plot_ue_subset(
    df,                          # DataFrame
    ue_ids,                      # List of UE IDs (required)
    figsize=(12, 8),             # Figure size
    title=None,                  # Custom title
    show_start_points=True,      # Mark starting points
    show_end_points=True,        # Mark ending points (enabled by default)
)
```

**Example:**
```python
# Quick plotting with automatic legend and end points
plot_ue_subset(df, ue_ids=[0, 5, 10, 15, 20])
```

### `plot_ue_tracks_comparison()`

Side-by-side comparison of two datasets.

**Parameters:**
```python
plot_ue_tracks_comparison(
    df1,                         # First DataFrame
    df2,                         # Second DataFrame
    legend=True,                 # Show/hide legend
    ue_ids=None,                 # Filter to specific UEs (applied to both)
    figsize=(20, 8),             # Figure size
    titles=None,                 # Tuple of (title1, title2)
)
```

**Examples:**
```python
# Compare all UEs from two scenarios without legend
plot_ue_tracks_comparison(df1, df2, legend=False)

# Compare specific UEs with custom titles
plot_ue_tracks_comparison(
    df1,
    df2,
    legend=True,
    ue_ids=[0, 1, 2, 3, 4],
    titles=("Urban Scenario", "Rural Scenario")
)
```

## Solutions to Common Issues

### Issue 1: Legend Too Long (75 UEs)

**Problem:** With many UEs, the legend board becomes too long and clutters the plot.

**Solutions:**

```python
# Solution 1: Disable legend (recommended)
plot_ue_tracks(df, legend=False)

# Solution 2: Plot only a subset with legend
first_10_ues = sorted(df['mock_ue_id'].unique())[:10]
plot_ue_tracks(df, legend=True, ue_ids=first_10_ues)

# Solution 3: Use automatic truncation (shows warning)
plot_ue_tracks(df, legend=True, max_legend_items=15)
```

### Issue 2: Filtering to Specific UE Doesn't Work

**Problem:** In legacy functions, `df[df['mock_ue_id'] == 5]` would fail due to batch detection logic.

**Solution:** Use the `ue_ids` parameter instead:

```python
# ❌ OLD WAY (doesn't work correctly)
filtered_df = df[df['mock_ue_id'] == 5]
legacy_plot_ue_tracks(filtered_df)  # Fails!

# ✅ NEW WAY (works correctly)
plot_ue_tracks(df, legend=True, ue_ids=[5])

# ✅ Multiple UEs
plot_ue_tracks(df, legend=True, ue_ids=[5, 10, 15])
```

**Why it works:** The new functions properly reset indices after filtering, avoiding the batch detection issues.

## Advanced Usage

### Filter by Movement Analysis

```python
import numpy as np

def calculate_distance(ue_data):
    """Calculate total distance traveled."""
    ue_data = ue_data.sort_values('tick')
    lats = ue_data['lat'].values
    lons = ue_data['lon'].values
    distances = np.sqrt(np.diff(lats)**2 + np.diff(lons)**2)
    return distances.sum()

# Find most mobile UEs
ue_distances = df.groupby('mock_ue_id').apply(calculate_distance)
top_5_mobile = ue_distances.nlargest(5).index.tolist()

# Visualize them
plot_ue_subset(df, ue_ids=top_5_mobile, title="Top 5 Most Mobile UEs")
```

## Migration Guide

### From Legacy to New Functions

```python

from radp.digital_twin.agentic_mobility.visualization.legacy import plot_ue_tracks as old_plot
old_plot(df)  # Legend always shows

# NEW: Enhanced function with legend control
from radp.digital_twin.agentic_mobility.visualization import plot_ue_tracks
plot_ue_tracks(df, legend=False)  # No legend

# OLD: Filtering doesn't work
filtered_df = df[df['mock_ue_id'] == 5]
old_plot(filtered_df)  # Breaks!

# NEW: Proper filtering
plot_ue_tracks(df, ue_ids=[5])  # Works!

# OLD: Side-by-side comparison

# NEW: Enhanced comparison
from radp.digital_twin.agentic_mobility.visualization import plot_ue_tracks_comparison
plot_ue_tracks_comparison(df1, df2, legend=False, ue_ids=[0, 1, 2, 3])  # Full control
```

## Tips & Best Practices

1. **For datasets with 20+ UEs**: Use `legend=False` to avoid cluttered plots
2. **For detailed analysis**: Use `ue_ids` to focus on specific UEs of interest
3. **For presentations**: Use `plot_ue_subset()` with carefully selected UEs
4. **For comparisons**: Use `plot_ue_tracks_comparison()` with matching `ue_ids`
5. **For large figures**: Increase `figsize` and `arrow_width` for better visibility

## Performance

The new functions are optimized for large datasets:

- **Proper index handling**: Avoids `.loc` issues with filtered data
- **Efficient colormaps**: Automatic selection based on number of UEs
- **Smart batching**: Correctly handles multiple simulation batches

Tested with datasets up to 200 UEs and 100 ticks with good performance.
